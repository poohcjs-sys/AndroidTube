# 유튜브 다운로더 0.3.2 — 삭제된 파일 보관함 정리

휴대폰의 ‘내 파일’ 등에서 삭제한 다운로드가 보관함에 계속 남던 문제를 수정했습니다. 보관함에 들어가거나 다른 앱에서 돌아오면 저장 위치를 백그라운드에서 확인하고, 삭제가 확인된 파일 기록을 제거합니다. **목록 새로고침**으로 직접 다시 확인할 수도 있습니다.

앱은 실제 파일을 삭제하지 않습니다. 보관함의 기록과 개수만 정리합니다. 저장 폴더의 권한이 없거나 연결이 끊긴 경우, 공급자가 오류·불완전한 목록을 반환한 경우에는 기록을 유지하고 확인 안내를 표시합니다. 선택한 폴더 안에서 이동했어도 기존 URI로 접근 가능한 파일은 유지합니다.

정리 중 새 다운로드가 완료되어도 새 기록을 덮어쓰지 않습니다. 완료 파일이 사라졌을 때 완료 화면이 엉뚱한 과거 파일을 여는 문제도 함께 막았습니다. 0.3.1의 **다운로드 성공 후 링크 입력창 자동 비우기**는 유지합니다.

[설치 APK](youtube-downloader-0.3.2-arm64.apk) · [소스 ZIP](youtube-downloader-0.3.2-source.zip) · [검증 기록](verification.json)

기존 앱을 삭제하지 않고 업데이트하세요. 앱 ID는 `kr.co.androidtube.pocketsave`, 버전 코드는 5이며 기존 서명을 유지합니다. Android 11 이상 ARM64용입니다. 저장 파일·품질·폴더 설정과 이전 링크 자동 정리 기능을 유지합니다.

검증은 기본 저장소와 사용자 선택 폴더의 삭제·접근 오류·불완전한 목록, 앱 복귀·명시적 새로고침, 동시 다운로드 기록 보존을 대상으로 합니다. 실제 S23의 삼성 ‘내 파일’과 YouTube 다운로드는 이번 클라우드 환경에서 재시험하지 않았습니다. 다운로드 엔진과 Android 권한은 변경하지 않았습니다.
