# 유튜브 다운로더 0.4.0 — 앱 안에서 YouTube 검색

앱 안에서 영상 제목이나 채널 이름으로 YouTube를 검색하고, 원하는 영상을 골라 저장할 수 있습니다. 별도의 API 키는 필요하지 않습니다.

1. **영상 검색** 탭에서 검색어를 입력하고 **YouTube 검색**을 누릅니다. 입력하거나 화면을 여는 것만으로 검색하지 않습니다.
2. 최대 15개의 결과에서 제목·채널·재생 시간을 확인하고 **이 영상 선택**을 누릅니다.
3. 영상 또는 음원 형식, 음원 품질, 저장 폴더를 선택한 뒤 다운로드 버튼을 누릅니다. 결과를 선택하는 것만으로 다운로드가 시작되지는 않습니다.

검색을 취소하거나 다른 화면으로 이동하면 진행 중인 검색을 중지합니다. 검색 응답이 60초 동안 오지 않으면 중지 안내를 표시하고 다시 시도할 수 있습니다. 화면을 회전해도 검색어와 결과를 유지하며, 이전 검색의 늦은 응답이 새 결과를 덮어쓰지 않습니다.

기존 **링크 붙여넣기**, **다운로드 성공 후 링크 입력창 자동 비우기**, **삭제된 파일의 보관함 기록 정리** 기능을 유지합니다. 검색이 제한되거나 실패하면 링크 붙여넣기를 이용할 수 있습니다.

[설치 APK](youtube-downloader-0.4.0-arm64.apk) · [소스 ZIP](youtube-downloader-0.4.0-source.zip) · [검증 기록](verification.json)

기존 앱을 삭제하지 않고 업데이트하세요. 앱 ID는 `kr.co.androidtube.pocketsave`, 버전 코드는 6이며 Android 11 이상 ARM64용입니다. 기존 0.3.2와 서명이 같고 Android 권한과 다운로드 엔진은 변경하지 않았습니다. 저장 파일·품질·폴더 설정을 유지합니다.

자동 검증 대상은 검색 요청·응답 처리, 취소와 시간 초과, 늦은 응답 차단, 화면 회전, 결과 선택 후 명시적인 다운로드 흐름입니다. **자동 테스트 86개 통과, 실패·오류·생략 0개. APK 빌드와 Lint도 통과했습니다(오류·경고 0개).** 합성 데이터로 일반 화면 및 320dp·글자 크기 130%의 검색 화면을 렌더링해 배치를 확인했습니다.

클라우드에서 실제 YouTube 검색을 시도했으나 네트워크 프록시가 `CONNECT 403`을 반환하여 검색 결과를 확인하지 못했습니다. 따라서 실제 휴대폰에서의 YouTube 검색·다운로드 성공 여부는 아직 검증하지 않았습니다.
